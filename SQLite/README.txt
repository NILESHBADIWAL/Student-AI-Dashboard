STUDENT AI DASHBOARD - PYTHON + MYSQL

1. Create the MySQL database
--------------------------------
Open MySQL Workbench and run the SQL file supplied with this project.

Database name:
student_ai_dashboard

2. Configure MySQL
--------------------------------
Open config.py and change:

"password": "YOUR_MYSQL_PASSWORD"

to your actual MySQL root password.

3. Install Python dependency
--------------------------------
Open terminal in this project folder and run:

pip install -r requirements.txt

4. Run the backend
--------------------------------
python main.py

5. Example questions
--------------------------------
What is the minimum attendance required?
What is the tuition fee?
Give me DBMS PYQs
What are the examination notices?
What are the library rules?
What are the hostel rules?

IMPORTANT
--------------------------------
Python connects to the MySQL Server.
MySQL Workbench is the GUI used to manage the MySQL Server/database.
